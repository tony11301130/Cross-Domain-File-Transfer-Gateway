# 這是一個可用的 Skills 清單

## Security & Penetration Testing
安全、滲透測試、漏洞評估與駭客技術相關技能。

### active-directory-attacks
- 當用戶要求「攻擊 Active Directory」、「利用 AD」、「Kerberoasting」、「DCSync」、「pass-the-hash」、「BloodHound 列舉」、「Golden Ticket」、「Silver Ticket」、「AS-REP roasting」、「NTLM relay」或需要 Windows 網域滲透測試指導時，應使用此技能。

### api-fuzzing-bug-bounty
- 當用戶要求「測試 API 安全性」、「對 API 進行模糊測試」、「尋找 IDOR 漏洞」、「測試 REST API」、「測試 GraphQL」、「API 滲透測試」、「漏洞賞金 API 測試」或需要 API 安全評估技術指導時，應使用此技能。

### aws-penetration-testing
- 當用戶要求「滲透測試 AWS」、「測試 AWS 安全性」、「列舉 IAM」、「利用雲端基礎架構」、「AWS 權限提升」、「S3 bucket 測試」、「metadata SSRF」、「Lambda 利用」或需要 Amazon Web Services 安全評估指導時，應使用此技能。

### broken-authentication
- 當用戶要求「測試身分驗證漏洞」、「評估連線管理安全性」、「執行憑證填充測試」、「評估密碼策略」、「測試連線固定」或「識別身分驗證繞過缺陷」時，應使用此技能。它提供了識別 Web 應用程式中身分驗證和連線管理弱點的綜合技術。

### burp-suite-testing
- 當用戶要求「攔截 HTTP 流量」、「修改 Web 請求」、「使用 Burp Suite 進行測試」、「執行 Web 漏洞掃描」、「使用 Burp Repeater 進行測試」、「分析 HTTP 歷史記錄」或「配置 Web 測試代理」時，應使用此技能。它提供了使用 Burp Suite 核心功能進行 Web 應用程式安全測試的綜合指導。

### cloud-penetration-testing
- 當用戶要求「執行雲端滲透測試」、「評估 Azure 或 AWS 或 GCP 安全性」、「列舉雲端資源」、「利用雲端設定錯誤」、「測試 O365 安全性」、「從雲端環境提取機密」或「稽核雲端基礎架構」時，應使用此技能。它提供了跨主要雲端平台的安全評估綜合技術。

### ethical-hacking-methodology
- 當用戶要求「學習道德駭客」、「了解滲透測試生命週期」、「執行偵察」、「進行安全掃描」、「利用漏洞」或「撰寫滲透測試報告」時，應使用此技能。它提供了綜合的道德駭客方法論和技術。

### file-path-traversal
- 當用戶要求「測試目錄遍歷」、「利用路徑遍歷漏洞」、「透過 Web 應用程式讀取任意檔案」、「尋找 LFI 漏洞」或「存取 Web root 之外的檔案」時，應使用此技能。它提供了綜合的檔案路徑遍歷攻擊和測試方法論。

### html-injection-testing
- 當用戶要求「測試 HTML 注入」、「將 HTML 注入網頁」、「執行 HTML 注入攻擊」、「竄改 Web 應用程式」或「測試內容注入漏洞」時，應使用此技能。它提供了綜合的 HTML 注入攻擊技術和測試方法論。

### idor-testing
- 當用戶要求「測試不安全的直接物件參考」、「尋找 IDOR 漏洞」、「利用破壞的存取控制」、「列舉用戶 ID 或物件參考」或「繞過授權以存取其他用戶的數據」時，應使用此技能。它提供了在 Web 應用程式中檢測、利用和修復 IDOR 漏洞的綜合指導。

### linux-privilege-escalation
- 當用戶要求「在 Linux 上提升權限」、「在 Linux 系統上尋找提權向量」、「利用 sudo 設定錯誤」、「濫用 SUID 二進位檔案」、「利用 cron 作業獲取 root 權限」、「列舉 Linux 系統以進行權限提升」或「從低權限 shell 獲取 root 權限」時，應使用此技能。它提供了識別和利用 Linux 系統上權限提升路徑的綜合技術。

### metasploit-framework
- 當用戶要求「使用 Metasploit 進行滲透測試」、「使用 msfconsole 利用漏洞」、「使用 msfvenom 創建 payload」、「執行後利用」、「使用輔助模組進行掃描」或「開發自定義 exploit」時，應使用此技能。它提供了在安全評估中利用 Metasploit Framework 的綜合指導。

### network-101
- 當用戶要求「設定 Web 伺服器」、「配置 HTTP 或 HTTPS」、「執行 SNMP 列舉」、「配置 SMB 共用」、「測試網路服務」或需要配置和測試滲透測試實驗室網路服務的指導時，應使用此技能。

### pentest-checklist
- 當用戶要求「規劃滲透測試」、「創建安全評估檢查清單」、「準備滲透測試」、「定義滲透測試範圍」、「遵循安全測試最佳實務」或需要滲透測試參與的結構化方法論時，應使用此技能。

### pentest-commands
- 當用戶要求「執行滲透測試指令」、「使用 nmap 掃描」、「使用 metasploit exploit」、「使用 hydra 或 john 破解密碼」、「使用 nikto 掃描 Web 漏洞」、「列舉網路」或需要基本的滲透測試指令參考時，應使用此技能。

### privilege-escalation-methods
- 當用戶要求「提升權限」、「獲取 root 存取權限」、「成為管理員」、「提權技術」、「濫用 sudo」、「利用 SUID 二進位檔案」、「Kerberoasting」、「pass-the-ticket」、「token impersonation」或需要 Linux 或 Windows 系統的後利用權限提升指導時，應使用此技能。

### red-team-tools
- 當用戶要求「遵循紅隊方法論」、「執行漏洞賞金狩獵」、「自動化偵察」、「尋找 XSS 漏洞」、「列舉子網域」或需要來自頂級漏洞賞金獵人的安全研究人員技術和工具配置時，應使用此技能。

### scanning-tools
- 當用戶要求「執行漏洞掃描」、「掃描網路開放埠」、「評估 Web 應用程式安全性」、「掃描無線網路」、「偵測惡意軟體」、「檢查雲端安全性」或「評估系統合規性」時，應使用此技能。它提供了有關安全掃描工具和方法論的綜合指導。

### shodan-reconnaissance
- 當用戶要求「搜尋網際網路上暴露的設備」、「執行 Shodan 偵察」、「使用 Shodan 尋找易受攻擊的服務」、「使用 Shodan 掃描 IP 範圍」或「發現 IoT 設備和開放埠」時，應使用此技能。它提供了使用 Shodan 的搜尋引擎、CLI 和 API 進行滲透測試偵察的綜合指導。

### smtp-penetration-testing
- 當用戶要求「執行 SMTP 滲透測試」、「列舉電子郵件用戶」、「測試開放郵件中繼」、「抓取 SMTP banner」、「暴力破解電子郵件憑證」或「評估郵件伺服器安全性」時，應使用此技能。它提供了測試 SMTP 伺服器安全性的綜合技術。

### sql-injection-testing
- 當用戶要求「測試 SQL 注入漏洞」、「執行 SQLi 攻擊」、「使用 SQL 注入繞過身分驗證」、「透過注入提取資料庫資訊」、「偵測 SQL 注入缺陷」或「利用資料庫查詢漏洞」時，應使用此技能。它提供了識別、利用和理解跨不同資料庫系統的 SQL 注入攻擊向量的綜合技術。

### sqlmap-database-pentesting
- 當用戶要求「自動化 SQL 注入測試」、「列舉資料庫結構」、「使用 sqlmap 提取資料庫憑證」、「從易受攻擊的資料庫傾印資料表和欄位」或「執行自動化資料庫滲透測試」時，應使用此技能。它提供了使用 SQLMap 檢測和利用 SQL 注入漏洞的綜合指導。

### ssh-penetration-testing
- 當用戶要求「滲透測試 SSH 服務」、「列舉 SSH 配置」、「暴力破解 SSH 憑證」、「利用 SSH 漏洞」、「執行 SSH 通道」或「稽核 SSH 安全性」時，應使用此技能。它提供了綜合的 SSH 滲透測試方法論和技術。

### top-web-vulnerabilities
- 當用戶要求「識別 Web 應用程式漏洞」、「解釋常見安全缺陷」、「了解漏洞類別」、「學習注入攻擊」、「審查存取控制弱點」、「分析 API 安全問題」、「評估安全設定錯誤」、「了解客戶端漏洞」、「檢查行動和 IoT 安全缺陷」或「參考與 OWASP 一致的漏洞分類法」時，應使用此技能。使用此技能提供跨所有主要 Web 安全類別的綜合漏洞定義、根本原因、影響和緩解策略。

### windows-privilege-escalation
- 當用戶要求「在 Windows 上提升權限」、「尋找 Windows 提權向量」、「列舉 Windows 以進行權限提升」、「利用 Windows 設定錯誤」或「執行後利用權限提升」時，應使用此技能。它提供了在 Windows 環境中發現和利用權限提升漏洞的綜合指導。

### wireshark-analysis
- 當用戶要求「使用 Wireshark 分析網路流量」、「擷取封包進行故障排除」、「過濾 PCAP 檔案」、「追蹤 TCP/UDP 串流」、「偵測網路異常」、「調查可疑流量」或「執行通訊協定分析」時，應使用此技能。它提供了使用 Wireshark 進行網路封包擷取、過濾和分析的綜合技術。

### wordpress-penetration-testing
- 當用戶要求「滲透測試 WordPress 網站」、「掃描 WordPress 漏洞」、「列舉 WordPress 用戶、佈景主題或外掛程式」、「利用 WordPress 漏洞」或「使用 WPScan」時，應使用此技能。它提供了綜合的 WordPress 安全評估方法論。

### xss-html-injection
- 當用戶要求「測試 XSS 漏洞」、「執行跨站腳本攻擊」、「識別 HTML 注入缺陷」、「利用客戶端注入漏洞」、「透過 XSS 竊取 cookie」或「繞過內容安全策略」時，應使用此技能。它提供了檢測、利用和理解 Web 應用程式中 XSS 和 HTML 注入攻擊向量的綜合技術。


## Software Development & Architecture
程式開發、架構設計、前端與後端開發最佳實務。

### backend-dev-guidelines
- Node.js/Express/TypeScript 微服務的綜合後端開發指南。當創建路由、控制器、服務、儲存庫、中介軟體，或使用 Express API、Prisma 資料庫存取、Sentry 錯誤追蹤、Zod 驗證、unifiedConfig、依賴注入或非同步模式時使用。涵蓋分層架構 (routes -> controllers -> services -> repositories)、BaseController 模式、錯誤處理、效能監控、測試策略以及從舊有模式遷移。

### bun-development
- 使用 Bun runtime 進行現代 JavaScript/TypeScript 開發。涵蓋套件管理、打包、測試以及從 Node.js 遷移。當使用 Bun 工作、優化 JS/TS 開發速度或從 Node.js 遷移到 Bun 時使用。

### claude-d3js-skill
- 使用 d3.js 創建互動式數據視覺化。當創建自定義圖表、圖形、網絡圖、地理視覺化或任何需要精細控制視覺元素、過渡或互動的複雜 SVG 基礎數據視覺化時，應使用此技能。將此用於標準圖表庫之外的客製化視覺化，無論是在 React、Vue、Svelte、原生 JavaScript 還是任何其他環境中。

### core-components
- 核心組件庫和設計系統模式。當構建 UI、使用設計 token 或使用組件庫工作時使用。

### frontend-design
- 創建具有高品質設計的獨特、生產級前端介面。當用戶要求構建 Web 組件、頁面、製品、海報或應用程式 (範例包括網站、登陸頁面、儀表板、React 組件、HTML/CSS 布局，或當樣式化/美化任何 Web UI) 時使用此技能。生成避免通用 AI 美學的創意、精緻代碼和 UI 設計。

### frontend-dev-guidelines
- React/TypeScript 應用程式的前端開發指南。現代模式包括 Suspense、lazy loading、useSuspenseQuery、具有功能目錄的檔案組織、MUI v7 樣式、TanStack Router、效能優化和 TypeScript 最佳實務。當創建組件、頁面、功能、獲取數據、樣式化、路由或使用前端代碼工作時使用。

### javascript-mastery
- 二十八個每個開發人員都應該知道的基本概念的綜合 JavaScript 參考。從原始型別和閉包等基礎知識到 async/await 和函數式程式設計等進階模式。當解釋 JS 概念、除錯 JavaScript 問題或教授 JavaScript 基礎知識時使用。

### react-best-practices
- 來自 Vercel Engineering 的 React 和 Next.js 效能優化指南。當撰寫、審查或重構 React/Next.js 代碼以確保最佳效能模式時，應使用此技能。當任務涉及 React 組件、Next.js 頁面、數據獲取、bundle 優化或效能改進時觸發。

### react-ui-patterns
- 用於載入狀態、錯誤處理和數據獲取的現代 React UI 模式。當構建 UI 組件、處理非同步數據或管理 UI 狀態時使用。

### senior-architect
- 使用 ReactJS、NextJS、NodeJS、Express、React Native、Swift、Kotlin、Flutter、Postgres、GraphQL、Go、Python 設計可擴展、可維護系統的綜合軟體架構技能。包括架構圖生成、系統設計模式、技術堆疊決策框架和依賴分析。當設計系統架構、做出技術決策、創建架構圖、評估權衡或定義整合模式時使用。

### senior-fullstack
- 使用 React、Next.js、Node.js、GraphQL 和 PostgreSQL 構建完整 Web 應用程式的綜合全端開發技能。包括專案 scaffolding、代碼品質分析、架構模式和完整的技術堆疊指導。當構建新專案、分析代碼品質、實作設計模式或設定開發工作流程時使用。

### software-architecture
- 以品質為重點的軟體架構指南。當用戶想要撰寫代碼、設計架構、分析代碼，在任何與軟體開發相關的情況下，應使用此技能。

### test-driven-development
- 當實作任何功能或 bug 修復時，在撰寫實作代碼之前使用。

### testing-patterns
- Jest 測試模式、工廠函數、mocking 策略和 TDD 工作流程。當撰寫單元測試、創建測試工廠或遵循 TDD 紅-綠-重構循環時使用。

### ui-ux-pro-max
- UI/UX 設計智慧。50 種風格、21 種調色盤、50 種字體配對、20 種圖表、9 種堆疊 (React、Next.js、Vue、Svelte、SwiftUI、React Native、Flutter、Tailwind、shadcn/ui)。操作：計畫、構建、創建、設計、實作、審查、修復、改進、優化、增強、重構、檢查 UI/UX 代碼。專案：網站、登陸頁面、儀表板、管理面板、電子商務、SaaS、作品集、部落格、行動應用程式、.html、.tsx、.vue、.svelte。元素：按鈕、彈出視窗、導航欄、側邊欄、卡片、表格、表單、圖表。風格：玻璃擬態、黏土擬態、極簡主義、粗獷主義、新擬態、便當網格、深色模式、響應式、擬真設計、扁平設計。主題：調色盤、無障礙性、動畫、佈局、排版、字體配對、間距、懸停、陰影、漸層。整合：用於組件搜尋和範例的 shadcn/ui MCP。

### web-artifacts-builder
- 使用現代前端 Web 技術 (React、Tailwind CSS、shadcn/ui) 創建精細、多組件 claude.ai HTML 製品的工具套件。用於需要狀態管理、路由或 shadcn/ui 組件的複雜製品 - 不適用於簡單的單檔案 HTML/JSX 製品。

### web-design-guidelines
- 審查 UI 代碼以符合 Web 介面指南。當被要求「審查我的 UI」、「檢查無障礙性」、「稽核設計」、「審查 UX」或「檢查我的網站是否符合最佳實務」時使用。


## AI, Agents & Prompt Engineering
人工智慧、Agent 開發、提示工程與 MCP 相關技能。

### agent-manager-skill
- 透過 tmux session 管理多個本地 CLI agent (啟動/停止/監控/指派)，並支援 cron 排程。

### autonomous-agent-patterns
- 構建自主編碼 agent 的設計模式。涵蓋工具整合、權限系統、瀏覽器自動化和人機協作工作流程。當構建 AI agent、設計工具 API、實作權限系統或創建自主編碼助手時使用。

### blockrun
- 當用戶需要 Claude 缺乏的功能 (圖像生成、即時 X/Twitter 數據) 或明確要求外部模型 ("blockrun"、"use grok"、"use gpt"、"dall-e"、"deepseek") 時使用。

### claude-code-guide
- 有效使用 Claude Code 的大師指南。包括配置模板、提示策略「思考」關鍵字、除錯技術以及與 agent 互動的最佳實務。

### dispatching-parallel-agents
- 當面臨 2 個以上可以在沒有共享狀態或順序依賴的情況下工作的獨立任務時使用。

### llm-app-patterns
- 構建 LLM 應用程式的生產就緒模式。涵蓋 RAG 管道、agent 架構、提示 IDE 和 LLMOps 監控。當設計 AI 應用程式、實作 RAG、構建 agent 或設定 LLM 可觀察性時使用。

### loki-mode
- Claude Code 的多 agent 自主新創系統。在 "Loki Mode" 時觸發。協調 100 多個跨工程、QA、DevOps、安全、數據/ML、業務營運、行銷、人力資源和客戶成功的專業 agent。將 PRD 轉化為完全部署、產生收入的產品，無需人工干預。具有用於子 agent 調度任務工具、具有 3 個專業審查者的平行代碼審查、基於嚴重性的問題分類、具有死信處理的分散式任務隊列、自動部署到雲端提供商、A/B 測試、客戶反饋循環、事件回應、斷路器和自我修復。透過分散式狀態檢查點和帶有指數退避的自動恢復處理速率限制。需要 --dangerously-skip-permissions 標誌。

### mcp-builder
- 通過設計精良的工具創建高品質 MCP (Model Context Protocol) 伺服器的指南，使 LLM 能夠與外部服務互動。當構建 MCP 伺服器以整合外部 API 或服務時使用，無論是使用 Python (FastMCP) 還是 Node/TypeScript (MCP SDK)。

### notebooklm
- 使用此技能直接從 Claude Code 查詢您的 Google NotebookLM 筆記本，以從 Gemini 獲得有來源依據、有引用的答案。瀏覽器自動化、圖書館管理、持久性身分驗證。透過僅限文件的回應大幅減少幻覺。

### prompt-engineering
